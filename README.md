## Build (Windows)
1. Install the latest Android Studio (it ships with JDK 21).
2. File > Open > select this folder, wait for Gradle sync (first time takes a while).
3. Build > Build Bundle(s) / APK(s) > Build APK(s), or from a terminal:
   `.\gradlew.bat assembleFossDebug`
4. APK output: `app\build\outputs\apk\foss\debug\`
